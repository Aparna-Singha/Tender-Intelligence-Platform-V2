# Pilot User Flow

## Supported path

1. Create an account or log in.
2. Create an MSME or Consultant organisation workspace.
3. Complete or save the eight-step organisation profile.
4. Upload reusable company evidence through private signed upload.
5. Create a tender workspace from known metadata.
6. Upload the tender, annexures and one corrigendum at a time.
7. Review processing, deterministic extraction and citations.
8. Review cited early risks and record an unselected-by-default human
   Continue/Hold/Stop decision with rationale and acknowledgement.
9. Compare machine proposals with append-only human evidence conclusions.
10. Resolve source-grounded checklist work without treating it as a score.
11. Ask tender-scoped cited questions when a provider is configured.
12. Generate and review a fact-constrained draft with citations and placeholders.

## Unsupported path

The pilot does not discover live tenders, scrape GeM or CPPP, bypass CAPTCHA,
submit bids, make autonomous declarations, run Phase 11 final readiness or export
Phase 12 packages. It provides no eligibility, compliance or success guarantee.

Tender Intelligence Platform is independent and not affiliated with GeM, CPPP or
any government authority.
